## Problems & fixes (environment)

| #   | Problem                                                                                                                                                                                      | Fix                                                                                                                                                                                                                                                                                                          |
| --- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 1   | `npm` (PowerShell shim `npm.ps1`) blocked by execution policy                                                                                                                                | Use `npm.cmd` / `npx.cmd` in shells; package scripts run through cmd so they are unaffected.                                                                                                                                                                                                                 |
| 2   | npm 12 refuses tarballs served from the corporate mirror host (`EALLOWREMOTE`, `allow-remote=none` is the npm 12 default)                                                                    | Local installs run with `NPM_CONFIG_ALLOW_REMOTE=all` (environment variable only, not committed).                                                                                                                                                                                                            |
| 3   | Lockfile would embed internal mirror URLs, breaking `npm ci` on GitHub runners                                                                                                               | Committed `.npmrc` sets `omit-lockfile-registry-resolved=true`.                                                                                                                                                                                                                                              |
| 4   | npm 12 blocks dependency install scripts unless covered by `allowScripts`; Electron 45 has no install script, its binary is fetched by `node node_modules/electron/install.js`               | Ran `install.js` once; `allowScripts` in `package.json` explicitly denies the two irrelevant scripts (`tesseract.js` funding banner, `electron-winstaller`) to keep installs quiet.                                                                                                                          |
| 5   | The active `gh` account (`t-atshukla_microsoft`) is an Enterprise Managed User and GitHub refuses public repos for it (`Public repositories are not permitted for Enterprise Managed Users`) | The repo lives under the second logged-in account of the same person (`snowjug`, name "Atharv Shukla"), where an empty public `Beekeeper` repo already existed. `gh`/`git` use that account through a per-command `GH_TOKEN` (no global `gh auth switch`). Commits use the account's GitHub no-reply e-mail. |
| 6   | `typescript-eslint@latest` dist-tag points at an alpha                                                                                                                                       | Pinned to stable `^8.72.1`. Same care for `@playwright/test` (pinned `1.64.1`) and Electron (`45.2.1`, the newest stable; the `latest` tag is an alpha).                                                                                                                                                     |
| 7   | eslint-plugin-react / jsx-a11y do not support ESLint 10 yet                                                                                                                                  | ESLint pinned to 9.39.x.                                                                                                                                                                                                                                                                                     |
| 8   | `vitest.config.ts` was loaded as CJS (package is not `type: module`)                                                                                                                         | Renamed to `vitest.config.mts`.                                                                                                                                                                                                                                                                              |
